# Test scope

The selected original tests and required companion source snapshots are retained. Preparation only copies and checks file bytes; it does not execute a scientific adapter or rerun its tests. Existing recorded results were 43 ranking, 52 robustness, 40 assembly and 32 ablation synthetic tests passing in their release environments. These are prior evidence, not tests of this new repository layout on Windows. The feature suite uses synthetic fixtures and inert worker output for integration tests; inspect its source before execution.

The test snapshots include original historical hard-coded project locations as code constants. These are retained for formula/source parity and are not current public bindings. Never execute snapshots directly against the official project. Synthetic tests redirect their source bindings in temporary workspaces. An administrator can bypass script-level controls; no OS sandbox is claimed.

All real-data replay templates are deliberately unbound. Do not change fixed weights, seed, thresholds, normalization or eligibility without a separate documented analysis. Public exports of results are not accepted substitutes for a full upstream schema where columns were intentionally removed.
