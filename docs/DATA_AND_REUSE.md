# Data provenance and reuse

Dataset1 is the recovered frozen 141-record cohort derived from public ClinVar/reference curation. The guide table contains 376 frozen computational records. Structural and bystander features were inherited from the supplied tables. The corrected feature stage used explicitly chosen archived raw hits, not a new BLAST search. Do not claim exhaustive variant ascertainment or transcriptome search coverage.

Raw reference and BLAST files are omitted. Their exact source hashes are recorded privately in the run evidence; a reproducibility archive and official reference links should be supplied in the manuscript data-availability statement. No download URL or raw-data DOI is invented here.

Before public distribution, verify source terms, code ownership and institutional licence requirements. NCBI public access does not automatically licence all third-party submissions or article supplements. No new patient data or third-party paper PDFs are included in this curated selection. Review this repository before changing its visibility.
