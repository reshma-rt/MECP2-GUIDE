# MECP2 Tier 1 computational guide prioritization

Computational prioritization of 376 frozen antisense guide records across eight MECP2 exact-restoration mutation groups, followed by 10,000 weight simulations and component ablation. The staged selection contains eight guide IDs representing six distinct RNA sequences.

## Scope

This repository concerns the corrected Tier-1 analysis. The historical 2,068-guide and expanded-cohort analyses are not presented as newly corrected results. These target-binding candidates have no demonstrated experimental editing efficacy, protein rescue or therapeutic validation. Off-target annotations are restricted to existing BLAST-discovered anchors and the declared reconstructed-window filters.

## Layout

- code/features: hash-bound feature launcher, bridge, proposed corrected processor, safeguard and synthetic tests.
- code/ranking, robustness, assembly, ablation: distinct downstream stages with local helpers, schemas, tests and unbound configuration templates.
- data/frozen_inputs: selected recovered tables, used as frozen inputs rather than proof of historical generation.
- results: supplied completed stage outputs. Assembly has a separately labelled public projection.
- figures: cohort, workflow, weight-frequency and ablation figures.
- docs: methods, data conventions, source lineage, test scope and public-export limitations.

## Environment

Recorded native interpreter: Python 3.10.11, Windows x64. Downstream adapters use Python standard-library modules and bundled helpers. No external pip package is required for the adapters. The historical ViennaRNA calculation is inherited, not regenerated by these stages. BLAST+ 2.17.0+ and reference release GCF_000001405.40-RS_2025_08 belong to the separately documented reference evidence. The large FASTA/database and raw search outputs are not bundled.

## Tests and execution

Tests are synthetic. From an isolated copy of a downstream module, its test entry point is `python -I -B run_tests.py`; the feature suite entry point is `python -I -B test_launcher.py`. They write fresh synthetic test outputs and must not be presented as experiments on the real guides. These commands are documentation only; preparation does not run them. Required source_snapshots/test_sources are preserved. Do not run source_snapshots as production scripts.

Unbound configuration templates intentionally cannot execute a real stage. Exact code/data/interpreter hashes, fresh paths and stage-specific approval records must be supplied for an independently reviewed replay. The preparation kit does not authorize scientific recalculation or official promotion. Moving files without adjusting reviewed bindings does not reproduce a run.

## Main results

Five robust selections matched baseline winners and three differed. Selected frequencies ranged from 27.49% to 76.24%, with five High and three Moderate labels under the specified weight distribution. Removing duplex stability, bystander precision, specificity or guide self-structure changed 7/8, 6/8, 3/8 or 0/8 baseline winners, respectively. These are internal decision-sensitivity results, not editing measurements.
